# Projects

One project card per `##` heading. The heading is the card title (start it
with an emoji). The list below the heading sets the fields:

- `url` (required): where the card links to.
- `image` (required): a file in `src/static/assets/`.
- `label`: the short URL line under the title. Default: `url` without `https://`.
- `embed`: an iframe URL shown over the image (for example a YouTube playlist).
  A card with an embed is not a link as a whole; only its label is.

Cards appear in the same order as in this file. Text outside the lists is ignored.
