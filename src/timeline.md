# Timeline

The "Timeline" section of the home page shows the entries in this file and all blog posts.
The section shows the newest entries first, grouped by the year of their start date.

Each `##` heading is one entry. The heading is the title of the entry.
The list below the heading sets the fields:

- `type` (required): `work`, `education`, `org`, `project`, `talk`, `award` or `cert`.
- `start` (required): the start date, as `YYYY`, `YYYY-MM` or `YYYY-MM-DD`.
- `end`: the end date, as `YYYY-MM`, or `now` for an entry that continues.
- `org`: the organization.
- `place`: the city or the country.
- `url`: a link for the title. Use a path such as `/blog/slug/` for a blog post.
- `text`: one or two sentences about the entry.

Do not add blog posts here. The build adds them from `blog/`.
The CV also uses some entries of this file (see `src/cv.md`). If you change the title of an entry, also change it in `src/cv.md`. Otherwise, the build stops with an error.
Text outside the lists is ignored.
